# IPv6 (AAAA) Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add full dual-stack IPv4+IPv6 support to the runtime pipeline (IP detection, state, cache, CLI, and update loop) with strict auto-routing (IPv4→A records, IPv6→AAAA records).

**Architecture:** Introduce a `PublicIps` enum (`V4`, `V6`, `Both`) that replaces all `Ipv4Addr` usage. The IP cache and update loop gain family awareness. Config-driven: the families needed are derived from which record types (A, AAAA) the user's zone configs target. Missing needed families are fatal errors before any mutations.

**Tech Stack:** Rust 2024 edition, tokio/reqwest, clap derive, serde/toml, derive_builder, color-eyre, indexmap.

## Global Constraints

- Hardcoded IP detection URLs (no config field for `public_ip_url`).
- IPv4→A, IPv6→AAAA routing only (no per-record family override).
- Old 2-column cache lines invalidated silently (no migration).
- Provider layer (`src/provider/`, `src/cloudflare_api/`, `src/bunny_api/`) untouched.
- `cargo build`, `cargo test`, `cargo clippy` must pass after all tasks.

use std::fmt;
use std::net::IpAddr;

use crate::provider::DnsRecordType;

#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize, serde::Deserialize)]
pub enum PublicIps {
    V4(IpAddr),
    V6(IpAddr),
    Both { ipv4: IpAddr, ipv6: IpAddr },
}

impl PublicIps {
    #[must_use]
    pub fn get_for(&self, record_type: DnsRecordType) -> Option<IpAddr> {
        match self {
            PublicIps::V4(ip) if record_type == DnsRecordType::A => Some(*ip),
            PublicIps::V6(ip) if record_type == DnsRecordType::AAAA => Some(*ip),
            PublicIps::Both { ipv4, ipv6 } => match record_type {
                DnsRecordType::A => Some(*ipv4),
                DnsRecordType::AAAA => Some(*ipv6),
                _ => None,
            },
            _ => None,
        }
    }
}

impl fmt::Display for PublicIps {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            PublicIps::V4(ip) => write!(f, "{ip}"),
            PublicIps::V6(ip) => write!(f, "{ip}"),
            PublicIps::Both { ipv4, ipv6 } => write!(f, "{ipv4} / {ipv6}"),
        }
    }
}
```

/// Caches the latest IPs (v4 and v6) for a given zone ID.
#[derive(Debug, Default, Clone)]
pub struct IpCache {

impl IpCacheReader {
    pub fn load(path: &Utf8Path) -> Result<IpCache> {
        if path.is_file() {
            let body = fs_err::read_to_string(path)?;

            let mut cache = IndexMap::new();

            for line in body.lines() {
                let parts: Vec<&str> = line.split(DELIMITER).collect();
                if parts.len() < 2 {
                    return Err(eyre!(
                        "Cache line should contain at least two values, separated by {DELIMITER}"
                    ));
                }
                let key = parts[0].to_owned();

                let v4 = if parts[1].is_empty() {
                    None
                } else {
                    Some(IpAddr::from_str(parts[1]).map_err(|e| {
                        eyre!("Invalid IPv4 in cache line: {e}")
                    })?)
                };

                let v6 = if parts.len() >= 3 && !parts[2].is_empty() {
                    Some(IpAddr::from_str(parts[2]).map_err(|e| {
                        eyre!("Invalid IPv6 in cache line: {e}")
                    })?)
                } else {
                    None
                };

                let ips = match (v4, v6) {
                    (Some(v4), Some(v6)) => PublicIps::Both { ipv4: v4, ipv6: v6 },
                    (Some(v4), None) => PublicIps::V4(v4),
                    (None, Some(v6)) => PublicIps::V6(v6),
                    (None, None) => {
                        return Err(eyre!(
                            "Cache line has no IP address (zone: {key})"
                        ));
                    },
                };

                cache.insert(key, ips);
            }

            Ok(IpCache::new(cache))
        } else if path.exists() {
            Err(eyre!("Cache file path exists, but is not a file!"))
        } else {
            Ok(IpCache::default())
        }
    }
}
```

impl IpCacheWriter {
    pub fn save(&self, ip_cache: &IpCache, path: &Utf8Path) -> Result<()> {
        let body = ip_cache.into_iter().fold(
            String::new(),
            |mut acc, (key, ips)| {
                let (v4_str, v6_str) = match ips {
                    PublicIps::V4(ip) => (ip.to_string(), String::new()),
                    PublicIps::V6(ip) => (String::new(), ip.to_string()),
                    PublicIps::Both { ipv4, ipv6 } => {
                        (ipv4.to_string(), ipv6.to_string())
                    },
                };
                writeln!(acc, "{key}{DELIMITER}{v4_str}{DELIMITER}{v6_str}")
                    .unwrap();
                acc
            },
        );

        fs_err::write(path, body)?;

        Ok(())
    }
}

```rust
async fn handle_zone<P: DnsProvider>(
    provider: &P,
    zone: &Zone,
    zone_config: &ZoneConfig,
    state: &mut ApplicationState,
) -> Result<()> {
    if zone_config.records().is_empty() {
        return Err(eyre!(
            "There are no records selected for update on zone '{}'.",
            zone.name
        ));
    }

    info!("Handling zone '{}'", zone.name);

    let public_ips = &state.public_ips;

    // Check cache — skip if IPs haven't changed (unless --force).
    if !state.force && !state.ip_cache.has_changed(&zone.id, public_ips) {
        info!("IP address unchanged: '{public_ips}'");
        return Ok(());
    }

    // We know IPs changed (or --force); log the reason.
    if state.force {
        info!("IP address: '{public_ips}', forcing update");
    } else {
        info!("IP address updated: '{public_ips}'");
    }

    let records = provider.list_records(zone).await?;
    debug!("Retrieved records for '{}':\n{:#?}", zone.name, records);

    let records_to_update: Vec<_> = records
        .iter()
        .filter(|r| zone_config.is_record_selected(&r.name, r.record_type))
        .collect();

    // Validate: every matched record must have a corresponding IP.
    for record in &records_to_update {
        if public_ips.get_for(record.record_type).is_none() {
            let family = match record.record_type {
                DnsRecordType::A => "IPv4",
                DnsRecordType::AAAA => "IPv6",
                other => {
                    return Err(eyre!(
                        "Record type '{other}' is not supported for IP updates"
                    ));
                },
            };
            return Err(eyre!(
                "Config targets {} record '{}' on zone '{}', \
                 but no {family} address was detected. \
                 Use --ipv{}-address to provide one or ensure {family} connectivity.",
                record.record_type,
                record.name,
                zone.name,
                if matches!(record.record_type, DnsRecordType::A) { "4" } else { "6" },
            ));
        }
    }

    debug!("Updating {} records:", records_to_update.len());
    for record in &records_to_update {
        debug!("{:>4}: {}", record.record_type, record.name);
    }

    for record in records_to_update {
        let ip = public_ips
            .get_for(record.record_type)
            .expect("validated above");

        if state.preview {
            info!("Would update {} to {ip}.", record.name);
        } else {
            info!("Updating {} to {ip}...", record.name);
            provider
                .update_record(zone, record, &ip.to_string())
                .await?;
        }
    }

    // Update cache only if changes were actually made (non-preview).
    if !state.preview {
        state.ip_cache.set(&zone.id, public_ips.clone());
    }

    Ok(())
}
```
